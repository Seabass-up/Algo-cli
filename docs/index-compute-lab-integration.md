# Retired Lab-index Routes

Algo CLI does not query, write, reindex, auto-inject, or enroll Lab-index.
Saved legacy flags cannot activate it. The old graph and embedding tools are
absent from model discovery; compatibility entry points refuse before IO.

Native Continuum is the mutable memory backend. Use explicit scoped native
memory operations. Local reference search uses `harness_search`, `harness_read`
and `harness_refresh`, without an embedding provider. References are retrieval
evidence, not proof; verify consequential claims with authorized live sources.

Historical stores remain intact and protected roots remain denied. The former
integration guide is preserved under `docs/history/`, outside live retrieval and
packaged resources. This notice does not authorize migration or data sharing.
