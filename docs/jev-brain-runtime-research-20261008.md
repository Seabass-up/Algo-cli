# Jev Brain Runtime: Research And Applied Changes

Date: 2026-10-08. Native active-launch source, local uncommitted qualification.

## Primary Sources

TypeSafe recommends software-controlled workflows with narrow typed semantic
judgments, not replacing open-ended reasoning or action control with Jev.
[Building guide](https://docs.typesafe.ai/concepts/how-to-build-with-system-one).

Uncertainty is a useful control signal; acceptance depends on the question and
consequences. Distribution concentration is not correctness or permission.
[Confidence guidance](https://docs.typesafe.ai/confidence).

Independent questions over one state can be batched and consumed separately.
[Fan-out pattern](https://docs.typesafe.ai/patterns/fan-out).

Literal reading, indirection, generation and irrelevant context are documented
Jev 1.13 limitations. Align instructions/criteria and retain arithmetic in code.
[Jaggedness guide](https://docs.typesafe.ai/model-jaggedness/jev-1.13).

Community Jevmind separates typed decisions, gates and outcome records. Its
author reports mock-transport rather than live-API qualification. Its raw tapes
and ledger are not adopted here; no third-party service, memory backend or
dependency was installed. [Project](https://github.com/dealerdefi/Jevmind),
[adapter proof boundary](https://github.com/dealerdefi/Jevmind/blob/main/docs/JEV.md).

## Supplied Case And Applied Runtime Patterns

The supplied Jev preference was 0.70, fit 0.84 and margin 0.49. Policy requires
0.80, 0.80 and 0.15 respectively. Only top probability failed. Kernel/algorithm
uncertainty did not cause that rejection. No provider outage was demonstrated.

1. Code composes route/fit judgments and exposes failed checks plus observed and
   required values. Acceptance thresholds and configuration remain unchanged.
2. Deferred receipts bind to the original request, operator policy, coordinator
   model, candidates and typed answers. Forged/stale/inconsistent claims fail.
3. Distinguish validated answer, completed-but-deferred routing and genuine error.
   Main-model continuation does not invent original answers or dispatch specialists.
4. Split next-investigation Choice from independent evidence-relevance Noul when
   excerpts exist. Kernel/algorithm questions remain separate catalog selections;
   one Choice no longer asks for open-ended reference generation.
5. Permit a budgeted follow-up after new evidence, not repeated tool/path/content
   fingerprints. No polling until a vote passes. Denials/failures stop retries;
   the three-checkpoint cap remains.
6. Preserve metadata-only router privacy, local-only restrictions, normal grants,
   signed budgets and actual outcome verification. No raw thought/history or
   Continuum packet is added to routing or a plaintext brain ledger.
