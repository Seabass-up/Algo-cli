# 0.20.3 Core CLI Release Scope

State: candidate preparation. Not published or available through the public
updater. Existing immutable tags, normal launchers and owner state stay unchanged.

## Included Scope

- Verified runtime reliability repairs: typed Jev coordination with preserved
  uncertainty/locality, bounded background work, stream interruption recovery
  without action replay, cancellation ownership and post-mutation verification.
- Continuum-only native memory integration, including applicability operations;
  retired embedding/reference backends do not become memory fallbacks.
- Backend-independent protected-root enforcement, credential redaction, bounded
  OAuth callback deadlines, connector-value redaction and gateway authentication.
- Go 1.26.10 pins and qualified website dependency repairs with real caller tests.
- Jev semantic regressions and shared prompt/tool guidance: type-valid model
  advice is not correctness or machine verification. Shell approvals and routing
  thresholds are unchanged; no improved provider weights/calibration is claimed.
- Refreshed managed Chrome 155.0.8059.84 pin and exact package/inventory bindings;
  fresh hosted browser evidence is required. Source pin refresh alone is not
  qualification.
- Public starter algorithm catalog and generic kernel framework only; no owner's
  personal catalog, custom kernel implementations, credentials or memory data.

## Excluded Scope

The signed native-browser companion and unfinished native authority bridge remain
disabled and unqualified. Blocked M8/M9 metrics and false public-claim eligibility
are retained. Local ARM64 emulation does not qualify hosted AMD64 browser isolation.
The website is not deployed by this release preparation.

## Required Gates

1. Final-source frozen installed parity, complete local tests, Python/Rust/Go
   quality and vulnerability gates, website clean install/build/lint/tests/audit,
   privacy scans over actual source/history/wheel/sdist and refreshed receipts.
2. Exact-source hosted Linux, macOS and Windows CI with clean wheel installation,
   sdist rebuild, preservation/upgrade fixtures and managed-browser attestations.
3. Protected publisher/source identity, repository/environment policy and approvals,
   exact asset/SBOM/provenance/checksum checks, immutable tag and trusted publishing.
4. Public registry visibility and exact bytes, then actual clean install,
   predecessor upgrade and repeat-update preservation verification.

The reviewed integration uses a normal PR based on freshly audited public main;
it does not force-push private local history or move the existing v0.20.2 tag.
Record source/publisher revisions, runs and public install receipts only when
those observations exist. No release success is implied by this scope document.
