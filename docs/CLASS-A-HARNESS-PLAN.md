# Class A Harness Improvement Plan

## Current Contract

Follow `ALGO.md`: implementation, activation, correctness, measurement, and
comparative benefit are separate evidence states. Native Continuum is the only
mutable agent-memory backend. Algo uses project `legacy-memory`, harness `algo`,
and an explicit `shared` or `private` scope on every operation. Echo Veil and
D-57 are retired, unrelated systems; their old selectors are accepted only as
inputs to fail-closed repair and never as backends or fallbacks.

Preserve approval boundaries, protected-root policy, source freshness, trusted
anchors, and external qualification blocks. A local pass does not establish a
public release, a production browser result, or superiority over another
harness.

## Workstreams

1. Runtime reliability: keep provider retry, cancellation, verification, and
   exactly-once mutation behavior source-bound and covered by executable tests.
2. Retrieval quality: measure catalog coverage, semantic relevance, stale-source
   rejection, dimension changes, and context cost against the installed source.
3. Continuity: qualify native Continuum status, context, revision-bound writes,
   receipt scanning, protected auxiliary stores, and explicit recovery without
   plaintext or retired-backend fallback.
4. Action authority: keep mode capabilities declarative, protect runtime-owned
   fields, and verify YOLO admission separately from program-shape validation.
5. Cross-platform delivery: qualify the exact commit and built distributions on
   hosted Linux, Windows, and macOS, including clean install and public upgrade.
6. External boundaries: retain blocked status for unqualified M8 browser metrics,
   Cobalt receiver behavior, native signing, or daemon persistence. Resolve each
   through its real external system rather than changing local evidence labels.

## Release Gate

A stable release requires a clean exact commit, same-SHA protected-main CI,
hosted Boron evidence, immutable tag and draft binding, reproducible wheel/sdist
checks, protected publication authority, exact PyPI bytes, and public clean
install/update verification. Do not move a tag, weaken an approval, lower test
or coverage gates, or convert a blocked metric into a pass to finish a release.
